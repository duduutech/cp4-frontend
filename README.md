## Sobre o Projeto
A aplicação consiste em uma plataforma de visualização de integrantes cadastrados em formato de cards. O desenvolvimento utilizou React.js, Vite, TypeScript com contratos de tipos centralizados e modularização de estilos com CSS Modules, seguindo as diretrizes semânticas da W3C.

---

## Tecnologias Utilizadas
- React.js com Vite
- TypeScript
- CSS Modules
- Padrões Semânticos W3C
